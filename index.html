Installing

Same four steps for every addon.

  1. Close WoWThe game only reads new addons on start.
  2. Download the zipClick an addon above, then its Download button.
  3. Extract into AddOnsDuring the beta: _classic_beta_/Interface/AddOns. You should see the addon's folder with its .toc inside.
  4. Enable itStart the game and tick it in the AddOns list on the character screen.
