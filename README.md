# marisco-addons
This is just a small repo of my addons to keep and share with friends.

All addons are for **World of Warcraft: Forever 1.60.x** (interface 16001).

**Showcase page:** https://the-tiagomapereira.github.io/marisco-addons/
**Downloads:** on the showcase page, or in the [downloads](downloads) folder. Everything at once: [MariscosAddons-Suite.zip](downloads/MariscosAddons-Suite.zip)

| Addon | Version | What it does |
|---|---|---|
| [Marisco's Cursor Tooltip](MariscosCursorTooltip/README.md) | 1.0 | Anchors every game tooltip to the mouse pointer, with a cursor ring and trail |
| [Marisco's Loot Cascade](MariscosLootCascade/README.md) | 1.0 | Replaces the loot window with a cascading feed of loot cards |
| [Marisco's Shellcracker](MariscosShellcracker/README.md) | 0.13.2 Release | A match-3 game against the makrura, with levels, talents and gear |
| [Marisco's MiniMapButtonHoarder](MariscosMiniMapButtonHoarder/README.md) | 0.5 Beta | One minimap button that holds all the others |
| [Marisco's Item Value Scanner](MariscosItemValueScanner/README.md) | 0.9 Beta | Vendor, Auction House and disenchant value on item tooltips |
| [Marisco's Profession Shopping List](ProfessionShoppingList/README.md) | 0.25 Beta | Profession materials shopping list with Auction House prices and leveling guides |
| [Marisco's Layout Bridge](MariscosLayoutBridge/README.md) | 0.2 Alpha | Converts retail Edit Mode layout strings for Forever |
| [Marisco's Companion Keeper](MariscosCompanionKeeper/README.md) | 0.7.1 Beta | Look after a companion: daily challenges, petting, fetch and walks together |
| [Marisco's Minimap Unbound](MariscosMinimapUnbound/README.md) | 0.1 Beta | Move the minimap, top bar and coordinates anywhere; square shape and border skins |

## Install
1. Close WoW.
2. Download the addon's zip from the showcase page or the [downloads](downloads) folder.
3. Extract it into `_classic_beta_/Interface/AddOns` (during the beta).
4. Start the game and enable the addon in the AddOns list.

Each folder here is the addon folder itself, named the way WoW expects it.
